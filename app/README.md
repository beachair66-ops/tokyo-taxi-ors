# 東京タクシールート

日本語UI・スマートフォン対応のルート比較アプリです。大きな音声入力ボタンから目的地を入力できます。

画面右上の「表示言語 / 界面语言」から日本語・中文を切り替えられます。選択は同じブラウザに保存されます。表示言語と音声認識の言語は別々に設定でき、入力した住所は変更されません。

## 機能

- 一般道優先。高速道路・有料道路は初期設定で避けます。
- 日本語・英語・中国語のブラウザ音声入力。ブラウザや端末によって対応状況が異なります。
- クラウド音声認識を設定すると、言語を指定せずに自動判定できます。最大20秒の録音をOpenAIへ送信します。
- ORSの実道路ルートと、明確に区別したデモルート。
- 距離（km）・所要時間（分）・地図表示・Google マップへのリンク。
- ChatGPT用MCPツール。詳細は `CHATGPT.md` を参照してください。

## Windowsで起動

Python 3.10以上が必要です。プロジェクトフォルダーで `python server.py` を実行し、`http://localhost:8000` を開きます。

実際のルート検索には、起動前にサーバー環境変数 `ORS_API_KEY` を設定してください。キーなしではデモのみ利用できます。ローカルPython版は自動言語判定に対応せず、言語を選ぶブラウザ音声入力を利用します。

## クラウド版の構築

Node.js 22以上を推奨します。追加のnpmパッケージは不要です。

```text
node scripts/build.mjs
node --test
```

`worker/index.js` とフロントエンドから `dist/server/index.js` を生成します。Sitesへ公開する際は、対象プロジェクトの `.openai/hosting.json` に実際の `project_id` と `capabilities: ["mcp"]` を設定してください。GitHubのソースには個人のプロジェクトIDを含めません。

クラウド環境変数：

| 名前 | 用途 |
| --- | --- |
| ORS_API_KEY | 実道路ルート検索 |
| OPENAI_API_KEY | 音声の自動言語判定・文字起こし（任意） |

環境変数を設定した後は再デプロイが必要です。音声認識はAPI利用料金が発生する場合があります。キーはサーバー側のシークレットとして設定し、GitHubやチャットへ投稿しないでください。`.env.example` は変数名だけを記載しています。

## iPhone

HTTPSの公開先をSafariで開き、共有メニューから「ホーム画面に追加」を選びます。位置情報やマイクは利用時に許可してください。私用サイトは本人のみアクセス可能に設定します。GitHub Pagesだけではこのバックエンドは動作しません。

## 注意事項

所要時間はリアルタイムの渋滞情報を含みません。タクシー運賃は計算しません。Google マップではルートが再計算されます。高速道路を避ける設定を再確認してください。外国語で認識した施設名が見つからない場合は、正式な日本語住所へ修正してください。デモの線・距離・時間は架空です。走行中の操作はお控えください。
